# STARK TECH Website Starter

Premium cinematic black and metallic-gold static website for STARK TECH — “SOLUTIONS BEYOND IMAGINATION”.

## Pages
- `index.html` — homepage
- `capabilities.html` — services
- `projects.html` — portfolio and project status placeholders
- `rnd-process.html` — development process
- `about.html` — company profile
- `contact.html` — project enquiry form

## Before launch
1. Replace image placeholders with real, approved STARK TECH workshop and project photos.
2. Confirm project descriptions, status and permissions to publish client/project details.
3. Replace `REPLACE_WITH_OFFICIAL_EMAIL` in `contact.html` with the correct business email.
4. Add actual contact/location details.
5. The enquiry form opens a prefilled email draft; it does not send/store submissions by itself. For a production form, connect a form service or Cloudflare Worker endpoint and test it.
6. Add a privacy notice that matches how you actually handle enquiry data.
7. Check every link and test desktop/mobile layouts before launch.

## Preview locally
Open `index.html` in a browser, or run `python -m http.server 8080` from this directory.

## Cloudflare Pages deployment
1. Put these files in a Git repository.
2. In Cloudflare, create a Pages project connected to that repository.
3. For this static site, use no build command and set the output directory to the repository root (`/` or `.` depending on dashboard).
4. Deploy and test the `pages.dev` URL.
5. Connect a custom domain later from the Pages project settings. Domain registration usually costs extra.
